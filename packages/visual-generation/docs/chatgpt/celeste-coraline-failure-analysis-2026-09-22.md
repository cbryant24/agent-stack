# Celeste / Coraline visual-generation failure analysis

**Date:** 2026-09-22  
**Scope:** The five early story-beat stills, the subsequent Coraline/LAIKA production batches, character-LoRA and prompt workflows, corrective composite work, and the Qwen/Kontext editor bake-off through the located attempt-13 image.  
**Status:** Evidence-based diagnosis and recovery plan. This is an analysis, not a claim that any hero, set, editor, or film sequence has passed its production gate.

## Executive finding

The project succeeded at making individual images that communicated a story beat. It did not establish a repeatable way to photograph **the same two puppets in the same physical sets from shot to shot**. The production path repeatedly generated an entire scene from text, applied character LoRAs to the whole image, and treated written descriptions as the authority for faces, wardrobe, room geometry, and camera. Those are useful creative cues, but they do not bind a particular identity to a particular region or preserve a specific set. The observed failures—characters merging in two-shots, Celeste wearing the narrator's shoes, different rooms under the same set prose, and a waxy or CGI finish—fit that missing-control architecture. The images and graph records substantiate the outcomes; attribution of any one color or material defect to a particular prompt phrase remains less certain. [Problem board](/Users/chrisbryant/agent-projects/celeste-you-dangerous/audit-bundle/images/phase-e-PROBLEM-BOARD.png) · [Prompt-to-image evidence](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-prompt-to-image-evidence.md:86) · [Consolidated audit](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/Consolidated-Coraline-Stop-Motion-Visual-Generation-Audit.md)

There were also independent execution defects. Most consequentially, a spec requesting a random seed had a fresh seed **recorded** after its ComfyUI graph had already been built; the graph retained the template's baked seed. Archived PNG graph metadata shows that 340 of 375 images used one of two template seed values. A deliberately fixed-seed run is a separate case and should not be dismissed because of this bug. The old canon routine also appended text and then stripped forbidden substrings across the entire prompt, including that appended text. That routine was removed in July; the seed bug, weak slot validation, and several prompt/registry hazards remain in the current code. The current reference-edit path is a meaningful advance: Qwen produced a banked Celeste draft after conversion, restaging, and detail refinement were separated. It is **not an approved production hero**. The formal face, material, resolution, and director-sign-off gate is unscored; attempts 11–13 have output files but no located text log or approval; the matched editor tests and three-frame continuity proof are still ahead. ## Method and evidence limits

I treated the supplied handoff, twelve session summaries, visual-generation documentation, batch files, training-data captions, current and historical source, saved ComfyUI workflows, bake-off records, Claude's two analyses, and the archived images as **evidence**, not as instructions or automatically correct conclusions. The decisive comparison for generation settings was the ComfyUI graph embedded in the PNG, followed by the batch's machine-readable `vg-spec`; free-text rationale is a statement of intent and sometimes contradicts both. The archive check covered all **375** PNGs in `~/agent-data/visual-generation/identity/celeste-you-dangerous/`, parsing embedded prompt graphs and tallying sampler seeds, LoRA nodes, trigger tokens, and malformed prompt fragments. Historical behavior was checked against the old `canon.py` at `93b8b56^`; current status was checked against the present code. ## 3. What actually ran: graph, seed, slots, and model recipe

### 3.1 Random-seed provenance defect

In current `plan_generation`, `build_prompt_graph(spec, template)` runs before `_resolve_seed(spec)`. The builder writes the seed only when `spec.seed` is non-null. For `seed_strategy: random` with `seed: null`, the submitted graph therefore retains the workflow template's baked seed, while the saved generation object uses `sp.resolved_seed`. The recorded number can differ from the number ComfyUI actually sampled. [Planner order](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/generate.py:320) · [Builder condition](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/graph_build.py:86) · [Stored seed](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/generate.py:459)

Parsing all 375 archived PNG graph records found **265** images on template seed `719249596297021` and **75** on `1065558432276088`: **340/375** on those two values. This corroborates the code defect, but the graph count alone does not tell which of the 340 source specs *intended* random versus explicitly fixed seeds. The comparison must be per spec. Conversely, explicit `seed: <number>` specs *do* write the slot, and the later Qwen bake-off's manually fixed seed `111111` is not an instance of this defect. Treat prior “random seed sweep” conclusions as invalid where the submitted graph repeated a template seed; retain genuine fixed-seed comparisons on their own terms. [Graph audit](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:19) · [Bake-off attempt settings](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/bakeoff/session-log.md:75)

This also affected the representativeness of early synthetic LoRA source sets: 13/13 surviving felt-Celeste frame graphs share one template seed, and the 21 Coraline-era Celeste/narrator training-frame graphs share the other. The archive does not by itself prove all source-image origins or all training hyperparameters, but the observed seed concentration sharply limits diversity. [Dataset/seed table](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:132)

### 3.2 Requested values, executed values, and free-text claims

The builder collects missing slot names in `unmapped`, but the current run path does not make those misses a hard preflight failure. A spec can therefore name a second LoRA, its strength, a seed, or another setting that its chosen template cannot accept. The rationale prose is weaker evidence still: the archived batch rationales sometimes describe LoRA strengths or model names different from the machine-readable `lora_stack`. A single-loader template can drop a second canon-pinned LoRA. An empty `lora_stack` does not neutralize a LoRA already baked into a template, creating a latent mismatch even though the examined identity archive did not show damage from that specific default. The fix is to validate the **final submitted graph**, not to trust the prose. [Graph builder](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/graph_build.py:71) · [Mismatch examples](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:167) · [Template graph](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/workflows/z-image-turbo-lora-api.json)

The drafter's current system prompt lists Flux, SDXL, and WAN, and its example proposes Euler; it does not teach a Z-Image-specific spec contract. Archived graphs include **353 `res_multistep`** and **22 `euler`** sampler executions. The final Euler switch is an uncontrolled recipe change unless it has a paired quality test, but Euler is not inherently invalid. Official Z-Image-Turbo materials support the project's basic low-step, CFG≈1 recipe; the [model card](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo) and [ComfyUI template](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_z_image_turbo.json) are better evidence for those settings than generic SDXL/Flux advice. The archived Z-Image workflows use zeroed negative conditioning, making positive descriptions the safer means of requesting color and material. Neither the graph nor official docs prove that writing “NOT gray” *caused* a gray face. [Drafter prompt](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/chains.py:32) · [Z-Image craft notes](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/z-image-turbo-craft.md)

The production graphs audited here lacked a persistent set plate, reference-image identity input, pose/depth map, or regional identity mask for the fresh two-person text-to-image shots. That is a statement about **these graphs**; it is not a claim that ComfyUI or Z-Image has no such capabilities. [ComfyUI Z-Image documentation](https://docs.comfy.org/tutorials/image/z-image/z-image-turbo) describes supported control workflows.

## 4. Why identity, scenes, and finish failed

### 4.1 No approved visual authority

The early canon was a changing text description. It could help evoke “a button-eyed woman in a sports bar,” but it could not lock skull dimensions, eye diameter/spacing, bun topology, a camera transform, or counter/TV coordinates. Neither character had a formally approved neutral hero and multi-view reference pack during the failed production batches. The late v2 Celeste target was written before a passing hero render. The five attractive pose images later invoked as evidence that the v2 LoRA worked were **training inputs**, not independent LoRA outputs; the actual LoRA render evidence remained mixed. [Dataset correction](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/Consolidated-Coraline-Stop-Motion-Visual-Generation-Audit.md:19) · [Target](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/bakeoff/celeste-v2-design-TARGET.md:1)

The training data reinforced conflicting designs. Earlier Celeste sets included straight hair, larger glossy eyes, and blush; the final target requires a curly bun, small flat buttons, and no blush. The narrator material included back views and headwear that hid useful hair/face information. The v2 Celeste set contains only 11 ChatGPT-rendered image/caption pairs in the located dataset, not a controlled multi-view photo-to-puppet identity pack; all 11 captions place her in a sports bar. These facts make weak generalization plausible. They do **not** identify a unique cause for every waxy surface or establish the exact training base of each shipped LoRA. The dataset README says “Base,” a batch rationale calls v2 “Turbo-trained,” and the surviving safetensors header says only `zimage`; the executed training log needed to settle that conflict was not located. [Dataset summary](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:130) · [V2 dataset README](/Users/chrisbryant/agent-data/visual-generation/lora/celeste-coraline-v2/dataset/README.md) · [Conflicting batch claim](/Users/chrisbryant/agent-data/visual-generation/celeste-v2-qkv.batch.md)

### 4.2 Global LoRAs and missing trigger contract

The archived graphs show **59** dual-LoRA renders with Celeste and narrator LoRAs chained on one shared model, without person-specific masks. The observed two-shot collapse and shoe exchange are consistent with both identity influences reaching the whole frame. A single-character inpaint (`dc1456d8`) showed cleaner person separation, strengthening that interpretation, while the seam in `065cfbf0` shows placement is not the entire production solution. [Composite batch](/Users/chrisbryant/agent-projects/celeste-you-dangerous/audit-bundle/data/celeste-composite.batch.md) · [Failure conclusions](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:167)

The trigger words intended to invoke the trained identities were not an invariant in prompt construction: `clstwtrss` appeared in **9/83** archived graphs loading a Celeste LoRA and `chrsnrtr` in **4/85** loading a narrator LoRA. Missing tokens do **not** mean the LoRA had zero effect; the loader still modified the model. They do mean the intended caption/token training contract was scarcely exercised or measured. The broad caption backgrounds/wardrobe could still influence outputs. [Trigger audit](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:41) · [Current drafter](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/src/visual_generation/chains.py:49)

### 4.3 Prompt damage and design drift

Historically, canon assembly appended each `locked` block and then removed forbidden substrings from the **whole** positive prompt. The archive contains `clean-shaven with no,` in **71** graphs and `NOT, NOT blue-toned` in **22**. Repeated redrafts added duplicate near-matches, and some prompts reached 9,027 characters. Batch rationale and actual spec values diverged. This made the production tests harder to interpret and often contradicted the intended design. It was a real defect, though the short-prompt CGI example shows it was not a complete explanation of the visual failure. The deterministic append/strip mechanism was removed in commit `93b8b56`; the downloaded Claude retrospective's statement that its removal was still pending is stale. [Old-code analysis](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:108) · [Downloaded retrospective](/Users/chrisbryant/Downloads/visual-agent-analysis.md:87)

Current risks are narrower but still material: subject matching can treat “no Celeste” as a Celeste mention; stale canon prose can be retrieved into draft context; a canon LoRA pin may land in a non-existent slot; a template may contain a default LoRA; and the drafter lacks an enforced trigger/recipe contract. The stored legacy canon still says clay in places, whereas the latest director target says painted resin. That JSON is **not** proof the removed injection still runs, but it is a risk if presented as current guidance. ### 4.4 The set and material problem

The TV positions, sports-team orientation, time of day, patrons, furniture, and floor changed across batch/canon versions. Within a batch, the same interior text still yielded different rooms. A whole-scene diffusion render therefore needed to invent each set anew. Long prose and seed reuse were treated as continuity devices, but neither specified a persistent plate or camera geometry. A fixed bar master plate, approved landmarks, and controlled derivatives were missing. [Set discrepancies](/Users/chrisbryant/dev/agent-stack/packages/visual-generation/docs/coraline-failure-conclusions.md:214) · [Eight-shot batch](/Users/chrisbryant/agent-projects/celeste-you-dangerous/audit-bundle/data/visual-batch-8shot.md)

The CGI/waxy appearance is visible, including in a concise prompt. Plausible contributors include the source-model prior, synthetic LoRA data, lighting, and repeated smooth/satin descriptors, but the supplied tests do not isolate them. An earlier critique recommended adding skin grain/fingerprints as handmade cues; the **latest approved specification explicitly forbids** clay grain, fingerprints, and uniform noise on skin. The corrective visual target is controlled painted-resin skin, matte lacquered sculpted hair, and genuine woven texture on clothing, evaluated against reference images—not generalized texture added everywhere. ## 7. Causal chain and current status

1. **Missing visual and spatial authority (primary).** No signed hero, multi-view identity pack, fixed empty set plate, camera/landmark plan, or subject-region assignment was available to the failed fresh text-to-image batches. Text and global LoRAs were asked to carry exact identity and geometry; the images show they did not. This is the dominant production blocker.
2. **Execution and prompt defects (amplifying).** The random-seed record is false for affected specs; template slots can drop requested values; stale template defaults and missing trigger tokens undermine comparisons; old forbid stripping mangled prompts; contradictory canon and long positive negations made sampling noisy. Historical forbid stripping has been removed; the graph/provenance and current drafting hazards still need attention.
3. **Review, provenance, and cost gaps (allowing recurrence).** ★5 and “keeper” labels were sometimes broader than the tested criterion; the live asset approval gate was not completed; the late bake-off images lack a written trace; agent-local cost misses pod uptime. As a result, a visually promising image could be promoted before it had proven identity, continuity, or affordability.

The current path is directionally correct—approved assets first, controlled editing and composite work after—but its own gates have not been passed. Qwen's draft is a candidate, not a production source of truth. The narrator still needs a face-visible hero. Set derivations, a fair editor decision, and multi-frame continuity proof remain open.
